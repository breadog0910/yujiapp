## 心灵树洞木牌白底（二次修复）
- 首版修复仍可见白边根因：页面 `tab2-forest.css:118` 对 `.tab2-entry-img` 套了 `url(#alpha-hard-edge)` 滤镜（`feFuncA discrete 0 1`，alpha<128→0 / ≥128→255 二值化）。首版边缘用"近白程度"做半透明 alpha 但未去白，二值化后把偏白的半透边缘像素变成不透明白边。
- 修复：改用白底抠图 + 白边去污染（decontamination）：`obj = 255 + (pixel-255)/alpha`，背景 d≤25→透明、d≥85→实心、中间按距离插值 alpha 并去白。结果 0 个"不透明近白像素"，边缘为木板本色，二值化后无白边。
- 注意：图标路径 `assets/tab2/d0c500e16498ab7de1ce28335ef8bef9.png` 由 DB `furniture_catalog`/`default_room_layout` 下发且带缓存；若仍见白底多为浏览器/部署缓存，需硬刷新或重新部署。对比图 `generated-images/treehole_fix_v2.png`。
