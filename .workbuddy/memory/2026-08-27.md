## 开发环境：WorkBuddy 嵌入 preview 沙箱的 fetch 限制
- 现象：在 WorkBuddy `present_files` 打开的 preview 浏览器里，yuji-app 页面能渲染（HTML/JS/资源经代理加载），但页面内 `fetch('http://localhost:3000/api/...')` 全部被沙箱代理拦截，POST 返回 `HTTP 501`（body 非标准 JSON、data.error 为空 → 前端抛「请求失败 501」）。`curl http://localhost:3000/api/auth/login` 直连 Express 完全 200。
- 结论：Express 和前端代码都没问题；是 preview 沙箱的跨网络边界限制。
- 解法：所有需要调用本机后端 API 的测试（登录、保存、轮询、AI 等）必须用**本机自带的 Chrome/Edge 浏览器**打开 `http://localhost:3000/` 和 `http://localhost:3000/admin/`，不要用 present_files 的 preview 标签。`present_files` 仅适合展示静态页面。
- 诊断信号：浏览器 F12 Console 出现 `POST /api/xxx 501 请求失败 501`（没有具体 error 文案）+ `curl` 同一接口 200 → 100% 是 preview 沙箱，换本机浏览器即可。

## 退出按钮不可见（pointer-events:none 父级陷阱）
- **坑**：`css/main.css` 里 `.status-bar` 设了 `pointer-events: none`（伪 iOS 状态栏、不挡内容），但早期方案往 status-bar 里追加退出 chip → 子元素继承 none，**按钮可以看见但无法点击**。
- **用户视角症状**："点按钮没反应"，以为是 JS 报错，实际是 chip 也被一并禁用。
- **最终方案（v4）**：放弃 status-bar 注入。改成在 `.app-container` 上**绝对定位浮动齿轮按钮** `.yuji-acct-fab`（top:32px, right:14px, 圆形 36px，自带 `pointer-events:auto`），点开展开下拉菜单 `yuji-acct-menu` 显示用户名 + 退出登录。预览账号则 fab 带绿色徽标 + 菜单顶部"🔄 预览"标。
- **结论**：凡是把可点元素塞进 `pointer-events:none` 父级，要么让子元素 `pointer-events:auto`，要么把按钮搬出去。后者更稳。`present_files` 仅适合展示静态页面。

## 喝水动画：走路 sprite 替换 + 交叉淡入循环（本次第二轮）
用户反馈：① 只要喝水小人不要跑步的；② 要"像动画一样连贯"，不要"像视频一样硬切轮播"。
实现（v29）：
- HTML（index.html + _test_index.html 同步）：`.xiaowo-sprite` 单节点 → `.xiaowo-drinking` 容器，里面叠 6 个 `.xd-frame[data-f="0..5"]`，每个 frame 的 background-position 锁住 sprite sheet 的一帧（0% / 16.667% / 33.333% / 50% / 66.667% / 83.333%）。
- CSS：删掉 `.xiaowo-sprite` 的 `xw-walk`；改用 6 个独立 opacity keyframes (`xd-f0..xd-f5`) 在 5s 周期内接力出现 + 3% 区间交叉淡入。Frame 0（举杯）和 Frame 3（闭眼喝）各 hold 较久，Frame 1/2/4/5 是过渡瞬间。
  - Frame 0: 0-24% 显示，27-69% 隐藏，72-100% 再显示
  - Frame 1: 24-27% 出现后立刻消失
  - Frame 2: 30-33% 出现
  - Frame 3: 36-57% hold（最长，喝的瞬间）
  - Frame 4: 60-63% 出现
  - Frame 5: 66-69% 出现，立刻过渡回 Frame 0
  - 每两个相邻帧的进出都覆盖同一 3% 区间，做出"渡过"感而不是"切换"感。
- 6 个 frame 共用同一张 `background-image`，但通过 `background-position` 锁帧 + `opacity` 软切换 = 真·动画感，不是 steps 硬切。
- `.xiaowo.mood-happy` 改成作用于父 `.xiaowo`（xw-jump），6 个 xd-frame 整体一起跳，与喝水循环不冲突。
- `tab1.js` 简化：`triggerXiaowoAction('water')` 直接 return（动画常驻循环，无需触发），其他任务保留 mood-happy。
- 版本号：`tab1-home.css?v=28 → ?v=29`，`tab1.js?v=28 → ?v=29`。`_test_index.html` 也同步到 v29。
