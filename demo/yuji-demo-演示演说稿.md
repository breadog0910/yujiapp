> **视频总时长**：约 4 分钟（不含可选彩蛋）

## 二、场景一｜此刻 · 平行小屋：看见自己（00:18 – 01:25）

**【画面】** 打开 App → 启动屏「正在准备你的小屋…」→ 登录 → 像素小屋全景，右上角幸福值 ❤ 与金币 0/20，下方「今天可以怎样照顾自己一点」气泡组

**【旁白】**

> 打开予己，回到只属于自己的平行小屋。
>
> 这里没有打卡，没有任务清单，只有几个今天可以对自己好一点的小气泡——喝水、深呼吸、伸个懒腰。

**【操作】** 长按「喝水」气泡约 1 秒 → 打勾 → 小我喝水动画 → 幸福值与金币上涨

**【旁白】**

> 长按一下，就是一次自我照顾。你看，屏幕里的小我会陪你一起完成。幸福值在涨，金币也在涨——予己的金币，只能通过自我关照来获得。

**【操作】** 点击像素小人「小我」→ 情绪记录弹窗 → 选心情 / 写一句 → 保存

**【旁白】**

> 点一下小我，记录此刻的心情。你的情绪，会被房间温柔地回应——记录、反馈、觉察，这就是予己的陪伴方式。

**【操作】** 点「布置」→ 拖动 / 缩放 / 旋转家具 → 家具库加新家具 →「完成」

**【旁白】**

> 房间可以自由布置。你按自己喜欢的方式，安放这个小家。

**【操作】** 点「存钱罐」→ 商店 → 用金币买一件家具

**【旁白】**

> 金币商店里没有氪金入口——善待自己之后，也记得犒劳自己。这是予己和成长类 App 最大的不同：没有压迫，只有奖赏。

**【操作】** 点「镜子」→《自我说明书》弹窗（AI 生成内容）

**【旁白】**

> 这里，会慢慢生长出一份只属于你的《自我说明书》。稍后我们会在星迹里，再回来看它如何被 AI 持续更新。

## 七、评委 Q&A 预判（备答）

**Q1：市面上成长类 App 那么多，予己的差异点？**
答：市面产品偏强打卡、强任务，对高敏感人群反而是额外压力。予己把成长做成「陪伴式轻游戏」：无打卡、无排行、无惩罚，数值只增不减，用四个场景把抽象的成长过程可视化，这是定位上的根本差异。

**Q2：无惩罚机制，用户会不会流失？**
答：流失不等于失败。予己的目标不是制造依赖，而是让用户在低压力下形成「记录—反馈—觉察」的习惯闭环。植物不枯萎、数据不归零，用户随时回来都还在，这本身就是最强的留存理由。

**Q3：AI 成本怎么控制？**
答：AI 采用可配置多供应商架构（OpenAI 兼容协议，如 DeepSeek），系统提示词 + 动态上下文控制 token；AI 只在「说明书总结、树洞引导、星点挖掘」等关键环节按需调用，而非每屏都请求。

**Q4：商业化怎么设计？**
答：Freemium。核心体验永久免费，增值部分有 Pro 会员（AI 深度报告、更多对话额度）、轻量内购（纯外观像素家具，无数值加成）、激励广告（用户主动观看换 AI 额度）、以及付费导出个人成长 PDF 档案。

**Q5：技术上有哪些难点？**
答：① 像素资源处理——自研 20+ Python 工具链，用 BFS Flood Fill 解决家具半透明背景透底问题；② 数据安全——所有表启用 PostgreSQL RLS 行级安全，用户只能读写自己的状态；③ 双模式架构——同一套代码可在 Supabase 云模式和本地 Express+SQLite 模式切换，兼顾演示与生产；④ 前端零依赖原生 JS，IIFE 模块化 + PWA 可离线。

## 八、加分口播（讲完功能后可选，约 20 秒）

> 技术层面，予己用原生 JavaScript 实现，零框架、零依赖，加载快、可离线；后端基于 Supabase——PostgreSQL 加行级安全，每个用户只能读写自己的数据；AI 能力通过 Edge Functions 以可配置的多供应商方式接入，DeepSeek、通义等一键切换。整个前端是纯静态站点，托管在 Vercel，全球访问都很快。
